UNITRANSPORT SHARE
===================

Proyecto web prototipo para transporte compartido universitario.

TECNOLOGÍAS
-----------
HTML5
CSS3
JavaScript

CÓMO ABRIRLO
------------
1. Descomprime la carpeta UniTransport-Share.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta.
4. Selecciona la carpeta UniTransport-Share.
5. Abre index.html.
6. Recomendado: instala la extensión "Live Server".
7. Clic derecho sobre index.html > Open with Live Server.

IMPORTANTE
----------
Esta es una versión visual/prototipo. Los usuarios, mapas GPS, pagos,
base de datos, autenticación real y ubicación en tiempo real todavía
deben conectarse a un backend y servicios externos.
